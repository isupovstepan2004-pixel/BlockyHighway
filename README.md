# BLOCKY HIGHWAY

Godot 4.3, GDScript, Compatibility renderer (Android-friendly). Весь контент (модели, текстуры, UI) генерируется кодом.

## Сборка APK через GitHub Actions
1. Залей содержимое папки в репозиторий (ветка main), включая скрытую папку `.github`.
2. Вкладка Actions -> "Build Android APK" (запускается при push или вручную, Run workflow).
3. После завершения скачай артефакт `BlockyHighway-apk`, распакуй, установи `BlockyHighway.apk`.

Пакет: `com.stepan.blockyhighway`, arm64-v8a, debug-подпись.

## Запуск на ПК
Открой папку в Godot 4.3+ и нажми F5. Клавиши: WASD/стрелки, Space - ручник, C - камера, R - сброс, T - время суток, Esc - меню.

## Структура
- scripts/core - автозагрузка Game (настройки, сохранения)
- scripts/cars - воксельный билдер, CarModel (кузов/кабина), данные 12 машин, фабрика, физика Vehicle, models/ (по скрипту на каждую машину)
- scripts/world - окружение, площадка, камера, тестовая сцена
- scripts/ui - главное меню, гараж, сенсорное управление

## Этап 2: машины
Sportcar, Sedan, SUV, Pickup, Van, Truck (тягач + фура, 5 осей), Bus, Taxi, Police, Hatchback, Racing Car, Off-road Truck.
У каждой своя воксельная модель, оси колёс, масса, привод, подвеска, сцепление, аэродинамика. Выбор и покраска — в Garage.

## Этап 3: езда, графика, разрушения
- Исправлено направление: газ — вперёд, тормоз/задний ход — назад (DRIVE_SIGN = -1 + автокалибровка). Скорость больше не упирается в ~3 км/ч.
- Новое небо (шейдер: облака, звёзды, луна, закат), горы, деревья, фонари, трава, MSAA/мягкие тени.
- Разрушения в стиле Teardown (scripts/cars/voxel_body.gd): удар выбивает воксели, края обугливаются, куски кузова отрываются и летят отдельными телами, пыль/искры/дым/огонь. Кирпичные стены и ящики рассыпаются. R — сброс и починка.

## Этап 4: новые карты
- **CITY** (scripts/world/city_map.gd): сетка 7x7 улиц, кварталы с небоскрёбами/парками, светофоры, трафик (traffic_car.gd), пешеходы (pedestrian.gd). Сбитая машина трафика становится обломком и ломается как твоя; сбитый пешеход отлетает без крови.
- **AMERICAN ROAD** (scripts/world/american_road.gd): петля ~4.3 км, холмы, виражи с наклоном, ограждения, ЛЭП, билборды, заправка и закусочная, мезы и леса, трафик в обе стороны.
- Выбор карты: PLAY -> SELECT MAP.

## Этап 5: разрушаемый мир, пешком, инвентарь
- **Выход из машины**: кнопка EXIT (или E) при скорости < 30 км/ч; ENTER CAR (или E) рядом с машиной.
- **Инвентарь (всегда есть)**: HAMMER, SHOTGUN, DYNAMITE, SPRAY (повторное нажатие на SPRAY меняет цвет). Управление: джойстик, USE (или F), JUMP, обзор драгом, цифры 1-4.
- **Разрушаемые объекты** (scripts/world/destructible_world.gd, voxel_protos.gd): здания, дома, деревья, фонари, светофоры, знаки, билборды, столбы ЛЭП, камни, заправка, закусочная. Сначала дешёвая заглушка, при первом уроне превращаются в воксельную конструкцию с реальной коллизией. Оторванные куски (этажи, кроны) падают как твёрдые тела и ломаются дальше.
- **Физика машины**: АКПП 6 передач, антибуксовка, АБС, руль зависит от скорости, помощь контрруля, стабилизация заноса, антикрен.
- **Повреждения машины**: вмятины вдоль удара, потеря мощности при разбитом перед, увод руля, отрыв колёс, огонь и взрыв бензобака.
